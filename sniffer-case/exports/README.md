Print orientation STLs (ASCII) and STEP files for base and lid live here, plus preview PNGs.

The v01 geometry-only 3MF (`can_case_v01.3mf`, both objects on a 256 mm plate) is in this folder. You can also re-export it with `python src/export_v01.py`, or slice the two STLs.
`work_v01/` reference models of the XIAO, plug, and CAN board are not print files and are not included.
